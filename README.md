# 🚀 ABOUT THE PROJECT

Capex Tracker is a modern web application designed to manage and track capital expenditures efficiently.  
The application helps users organize expenses, monitor spending, and maintain financial records in a structured way.

---

# ✨ FEATURES

- 📊 Expense Tracking Dashboard
- 💰 Capital Expenditure Management
- 📁 Organized Financial Records
- ⚡ Fast & Responsive Interface
- 🌐 Web-Based Accessibility
- 📈 Real-Time Data Handling

# 💻 INSTALLATION

## 📥 Clone the Repository

```bash
git clone https://github.com/Hitesh2810/capex-tracker.git
cd capex-tracker
```

---

## 📦 Install Dependencies

```bash
npm install
```

---

## ▶️ Run the Application

```bash
npm start
```
